# Improvement Backlog

This list is based on static review of the code. Failures have not been reproduced unless stated otherwise. Entries describe current gaps; they are neither authorization to make changes nor a historical log. Locations name files and symbols so another engineer can continue the work. Remove resolved entries and update the related design, tests, and handoff evidence.

Priorities: P0 blocks the stated public-deployment scope; P1 covers contract, reliability, and collaboration issues; P2 covers maintainability. Evaluate production-readiness gaps separately from defects in the current local scope.

| G-02 | P2 / code | Ruff and ESLint are configured; Python formatting and type checking are not standardized.
